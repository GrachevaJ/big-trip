# Большое путешествие (Big Trip) — планировщик маршрутов

Интерактивное SPA-приложение на нативном JavaScript для детального планирования маршрутов, расчёта стоимости поездок и управления точками путешествия.

---

## 🛠 Технологический стек

* **Core:** JavaScript (ES6+, ООП), HTML5, CSS3
* **Архитектура:** MVP (Model-View-Presenter)
* **Библиотеки:** Flatpickr, Day.js, Chart.js / He
* **Сборка и качество кода:** Webpack, Babel, ESLint (стандарты HTML Academy)

---

## ✨ Реализованный функционал

* **Архитектура MVP без фреймворков:** Приложение спроектировано по паттерну **Model-View-Presenter** с чётким разделением логики данных, UI-компонентов и презентеров.
* **Управление маршрутом (CRUD):** Создание, редактирование и удаление точек маршрута, выбор города назначения с подгрузкой описания и фотографий, добавление дополнительных опций.
* **Фильтрация и сортировка:** Динамическая сортировка точек (по дате, времени в пути, цене) и фильтрация по временным статусам (будущие, текущие, прошедшие).
* **Синхронизация с сервером и UX:** Асинхронная работа с REST API, блокировка интерфейса во время запросов, отображение состояний загрузки и визуальная обратная связь при ошибках сети.
